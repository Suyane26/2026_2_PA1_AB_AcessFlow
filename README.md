# AccessFlow 🚌📱

**O celular é o passe.** Uma plataforma mobile-first de mobilidade urbana, com app para o usuário final e painel web de gestão para instituições. O AccessFlow transforma o smartphone na própria credencial de embarque, com validação instantânea por NFC ou QR Code dinâmico, inclusive offline.
